# Leader Drops site

The files served at https://launchpad-leader-drops.netlify.app (invites at
`/drop/<code>`, dashboard at `/admin`). Plain HTML/CSS/JS — no build step.

The database settings are in `assets/config.js`. It shares the Career Hub's
Supabase project (launchpad-career-hub).

To publish a change: drag this whole folder onto the site's Deploys page in
Netlify (Deploys → "drag and drop your project folder").
